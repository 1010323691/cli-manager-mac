# 续跑与交接

命令中的 `$R` 为 `scripts/delegate.py` 的绝对路径。先用 `task status` 查看任务状态、当前尝试、诊断和工作目录。尝试仍活动时，用 `task watch` 等待其停下。

## 续跑、重试和等待额度

```bash
python3 "$R" task status patch
python3 "$R" task resume patch --note '先核对上次检查点，再完成剩余测试'
python3 "$R" task retry patch --note '按审核意见重新执行'
```

- `task resume` 重新入队，沿用尝试 ID、原生会话、实例、账户登录代次、工作目录和能力档位。会话与目录须仍然存在，依赖版本须一致。已有检查点时，启动前比对工作树里的受控文件：被忽略的文件不算偏离，所以主会话可以往工作树里放截图、日志等被忽略的文件后再续跑。受控文件被改动时续跑失败，诊断里列出文件名。上一轮被拒绝的越界请求在续跑的会话里仍然视为已拒绝。`stale` 和生图任务无法原生续跑。
- `task retry` 重新入队并创建新尝试，从冻结的基线与当前获批依赖开始。已有交接时沿用交接材料和目标。上一尝试撞限时，重试仍绑定原实例。两个命令都可用 `--note` 提供补充指示，省略时沿用已有备注。已经取消或应用的任务不能直接重试。
- `waiting_quota` 保留检查点和等待时间。当前执行结果提供已用满窗口的恢复时间时，取其中最晚时间再加 30 秒。没有时间时，从 60 秒退避到最多 1800 秒。队列到时再次判断额度。有可用原生会话的代码或审查任务沿用原尝试，生图重新启动。需要持续等待时保持队列运行。
- 审核退回的任务处于 `changes_requested`。有可用原生会话时可继续修订，必要时重试或交接。先记录具体问题和复验要求，见 [审核与应用](review-and-apply.md#审核报告与运行验证)。

## 准备和启动交接

```bash
python3 "$R" task handoff prepare patch
python3 "$R" task handoff start patch --source "$SOURCE_ATTEMPT" --to codex1 --brief "$HOME/handoff.md"
```

1. 当前尝试已停止，任务处于允许交接的状态。代码与审查任务须有检查点。先运行 `prepare`，读它返回的 `material` 路径、`source` 尝试 ID 和 `preauthorized` 名单。素材含原简报位置、当前尝试报告、工作树和检查点。审批摘要来自该尝试当前记录的运行日志。
2. 由主会话写 UTF-8 交接简报，列出目标、已完成的证据、剩余步骤、验证结果以及仍适用的权限和决策。目标收到原任务作为背景，同时收到这份交接简报。
3. 用当前源尝试 ID 运行 `start`。目标必须是另一个已绑定账户的实例，且满足调度能力。目标未在提交时通过 `--handoff-to` 预授权，或预授权后换过账户时，先获得授权，再在 `start` 上加 `--authorize-target`。源尝试撞限后，同服务方目标必须绑定与源尝试不同的账户键。生图只允许 Codex 目标。
4. 能力档位随任务交给目标实例。提交时用 `--handoff-to` 写明、且此后没有换过账户的目标，已随任务一并授权。其他情况（目标未预授权，或预授权后切换过账户）要先获得授权，再在 `start` 上加 `--authorize-access`；`full` 档还要加 `--confirm-full` 并由用户在交互式终端确认。目标实例的 Codex 缺少所需能力时 `start` 报错。事件 `handoff_queued` 记录带过去的档位和是否重新授权。
5. `start` 将同一任务 ID 重新入队。下一次尝试在目标实例上运行。代码任务先核对依赖版本与基线，再用源检查点恢复并校验工作树。继续用原任务 ID 监控。`--model` 和 `--effort` 可指定目标参数，省略时同后端沿用原参数，跨后端使用目标默认值。

Codex 之间交接代码或审查任务时，控制器先恢复并校验检查点，再把该线程唯一匹配的 rollout 复制到目标实例的相同相对路径，通过 `thread/resume` 续跑，并附上主会话简报。复制不会覆盖同名文件。Claude 和跨服务方交接使用新会话。

缺少会话或 rollout、复制失败、恢复请求被拒，或恢复后的首轮在调用工具前以非额度错误失败时，控制器用原任务和交接简报启动新会话。额度错误按撞限处理。`task status` 的尝试记录以 `handoff_mode` 显示 `migrated` 或 `brief`，回退原因也记入事件和报告。同一 Business 工作区内已有跨账户实测，跨工作区尚未实测，加密推理内容可能被拒绝。

源码对应 [尝试恢复、重试、交接与等待](../scripts/cli_manager/controller.py) 和 [工作树恢复校验](../scripts/cli_manager/workspace.py)。
